# Gensini 评分计算器优化版

这是一个离线可用的本地网页工具，用于根据冠脉造影手术记录计算 Gensini 评分。

## 当前版本

已升级为“优化版”，支持三种计算模式：

- `中华版`
  按你最新提供的中文规则实现。
  不考虑冠脉优势，不做侧支循环校正。
  支持 `LCX中段×1`、`钝缘支(OM)×1`，并将 `左回旋支后侧支×0.5` 与 `右冠后侧支×0.5` 分开计算。
- `文献原始版`
  按参考文献《A guide for Gensini Score calculation》实现。
  支持优势型识别、LCX 中段与 OM 分支系数、以及 99%/100% 病变的侧支循环校正。
- `简化临床版`
  按你最初提供的规则实现，适合直接沿用你当前研究口径。

## 已实现能力

- 支持直接粘贴原始中文冠脉造影记录。
- 支持插入结构化录入模板，逐分支填写最严重狭窄程度。
- 支持原始病历中的常见写法，如 `近中段`、`中远段`、`OM1/OM3`、`完全性闭塞`、`次全闭塞`。
- 支持自动识别 `优势型` 和 `侧枝循环`。
- 支持在结果表格中手动修改各分支狭窄百分比，并实时重算。
- 对肌桥、斑块浸润、内膜不规则等不适合直接量化的描述保持谨慎，不会擅自编造分数。

## 使用方法

1. 用浏览器打开 [index.html](C:/Users/hf/Documents/New%20project%203/index.html)。
2. 选择计算模式：`中华版`、`文献原始版` 或 `简化临床版`。
3. 直接粘贴手术记录，点击“解析并计算”。
4. 如果记录写法不规则，可点击“插入录入模板”后按分支补充。
5. 检查解析结果表格中的狭窄百分比，必要时手动修正。
6. 如果想先做结构化摘录，再进入评分区录入，可参考 [TEMPLATE.md](C:/Users/hf/Documents/New%20project%203/TEMPLATE.md)。

## 中华版要点

- 狭窄严重度分值：
  `≤25%=1`，`26%~50%=2`，`51%~75%=4`，`76%~90%=8`，`91%~99%=16`，`100%=32`
- 分支系数：
  `LM×5`
  `LAD近段×2.5`
  `LAD中段×1.5`
  `LAD远段×1`
  `D1×1`
  `D2×0.5`
  `LCX近段×2.5`
  `LCX中段×1`
  `LCX远段×1`
  `OM×1`
  `LCX后降支×1`
  `左回旋支后侧支×0.5`
  `RCA近/中/远段及后降支×1`
  `右冠后侧支×0.5`
- 不考虑冠脉优势。
- 不做侧支循环校正。

## 参考文献原始版要点

- 狭窄严重度分值：
  `1–25%=1`，`26–50%=2`，`51–75%=4`，`76–90%=8`，`91–99%=16`，`100%=32`
- 对 `99%` 且有侧支供应的病变，按文献减 `8` 分。
- 对 `100%` 且有侧支供应的病变，根据供体血管狭窄程度进行减分。
- 支持区分 `右优势` 和 `左优势`，左优势时 LCX 部分节段系数更高。

## 简化临床版要点

- 狭窄严重度分值：
  `<25%=1`，`25%≤狭窄<50%=2`，`50%≤狭窄<75%=4`，`75%≤狭窄<90%=8`，`90%≤狭窄<99%=16`，`≥99%=32`
- 采用你最初提供的分支系数。
- LCX 中段和 OM 分支在该模式下仅记录，不自动计分。
